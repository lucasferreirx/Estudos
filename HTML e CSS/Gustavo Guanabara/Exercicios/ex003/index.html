Para colocar uma imagem dentro de um site, vc deve utilizar a tag img

E para deixar essas imagens a disposição para usar, você deve deixa-lás na mesma pasta que o arquivo do site.

Além disso, para você selecionar uma imagem de forma mais fácil dentro da tag "img", basta você apertar "ctrl"+"espaço" no seu teclado, assim irá abrir um menu que seleciona as imagens a disposição

Lembre-se sempre também de antes mesmo de usar o CSS, com o própio Gimp ajuste a imagem para quando adicionar ela em HTML mesmo deixar em um tamanho bacana para o seu site, isso porquê irá fazer com que o seu site fique menos pesado, e site menos pesados convertem mais no Google 🫡
