Formatações de texto

Negrito

Pode utilizar a tag B para negrito como está nesse texto, por exemplo,no entanto, ele ficará como forma e não como semâtica

Para dar sentido de significado você deve utilizar a tag STRONG, pode ver nesse texto, por exemplo, que ele ficará igual

Itálico

Igual ao negrito, no itálico você possui uma tag com significado e outra sem significado, que são respectivamente a tag I e a tag EM, pode ver que os dois textos estão igualmente em itálico mas para o HTML eles possuem significados diferentes, que nesse caso é a segunda tag que possue um significado também

Texto marcado

Você pode deixar o fundo dos seus textos marcados utilizando a tag Mark, olha aí: Lorem ipsum dolor sit amet consectetur

Texto deletado

É aquele texto que possui um risco no meio, tipo assim, para isso você utiliza a tag Del

Texto sublinhado

Você utiliza a tag "INS"

Texto sobrescrito e subscrito

Para textos sobrescritos você utiliza a tag "SUP", veja: X20+4

Para textos subscritos você utiliza a tag "SUB", veja: H2O
